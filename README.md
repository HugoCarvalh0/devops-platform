# DevOps Platform

Laboratório DevOps corporativo desenvolvido para demonstrar um fluxo completo de:

**Código → Testes → Segurança → Build → Deploy → Monitoramento**

## Tecnologias

- GitHub
- GitHub Actions
- Docker
- Kubernetes
- Argo CD
- Trivy
- Gitleaks
- Prometheus
- Grafana
- Loki
- OpenTelemetry
- Terraform
- Azure
